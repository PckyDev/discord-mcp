# Discord MCP: Your agent meets Discord

## Revision direction

The user found the 25-second cut crowded and difficult to follow. This edit is
74 seconds, deliberately overriding brag's short-form default. Separate asking,
sending, and seeing the result. Never show multiple feature demos simultaneously.
Keep the original film unchanged for comparison.

## Planning rubric

1. Product: an MCP bridge lets agents act through an authorized Discord bot.
2. Strongest claim: an agent can build out a community's channels, forums and roles
   from a natural-language request, inside an existing server the bot has joined.
3. Hook: the exact large headline "Your agent meets Discord" with the actual icon.
   No small kicker above it, and no competing subtitle.
4. Product material: original icon plus illustrative, source-backed Discord UI.
5. Duration: 74 seconds, 1920 x 1080 at 30 fps. The user's pacing request controls.
6. Tone: polished, Apple-like restraint with Discord colors and familiar surfaces.
7. Audio: extend the original electronic score to 74 seconds with a softer pulse.
   Minimal send/toggle accents; no narration.
8. Caption: "Your agent meets Discord. Ask it to build your community, configure
   your server, and take care of the everyday."
9. Flow: type a request, visibly send it, then watch the authorized result.

## Visual direction

Use #0C0D14 canvas, #F5F5FC text, #5865F2 accent, #A6ADFF accent text, and local
Manrope. Keep the familiar icon, but reduce persistent chrome to a small brand
lockup. Large 100px scene titles, 42px prompt text, generous margins. No three-card
grid, list of features, redundant mini-headlines, or simultaneous request/result
views. Soft exits and deliberate holds. The background light is restrained.
