# Discord MCP: Just ask.

## Planning rubric

1. Product: a local MCP bridge lets agents operate an authorized Discord bot.
2. Strongest claim: a single natural-language brief can build out a whole community server, including categories, channels, forums and roles.
3. Visual hook: enormous "Your server. Just ask." typography meets the actual glossy Discord MCP icon.
4. Product material: the source icon and tool-backed actions, demonstrated in a purpose-built, illustrative Discord interface. This plugin has no standalone graphical interface.
5. Shortest satisfying film: 25 seconds, landscape 1920 x 1080, 30 fps.
6. Tone: polished; Apple-like launch-film restraint with Discord's playful blurple and dark surfaces.
7. Audio: original warm electronic score at 110 BPM, with three restrained families of CC0 interface accents. No narration requested or generated.
8. Share caption: "Your Discord server. Just ask. Discord MCP lets your agent build channels, configure roles and permissions, and handle the everyday work of running a community."
9. User flow: invite bot into an existing server, describe the desired setup to an agent, review the plan, watch the authorized changes assemble, then ask for ongoing tasks.

## Visual identity

- Canvas #0C0D14, text #F5F5FC, Discord blurple #5865F2, readable accent #A6ADFF.
- Display/body: locally bundled Manrope, weight 400 to 800.
- Actual icon: ../assets/icon.png, copied without modification.
- Cinematic UI surfaces with deliberate depth; tiny chrome only when nonessential to the message.
- No unsupported claim that the bot creates a new Discord guild. The example starts with an empty server the bot has joined.

## Storyboard

### 0.00 to 3.27: The invitation

"Your server." lands, followed by "Just ask." The actual plugin icon emerges beside the words with a slight perspective settle. One quiet tonal impact. Two words hold fully readable for more than 1.5 seconds.

### 3.27 to 10.36: A community takes shape

An empty "Orbital Collective" server assembles: START HERE, welcome, rules; COMMUNITY, general, introductions, ideas forum; VOICE, Lounge. A role chip trio lands: Admin, Moderator, Member. A Discord-style roles/settings panel arrives on a shared lateral move. Moderator and Member roles settle into a list, channel permissions switch to Enabled, and slowmode resolves to 10 seconds. A small "Approved" state precedes the settings change. No unreadable matrix of permission bits.

### 16.36 to 21.27: Keep the community moving

Sequential entrances hold together for at least 2 seconds. Labels along the lower edge add Moderation, Events, Forums, Messages without attempting to explain every endpoint.
