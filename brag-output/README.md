# Discord MCP launch film

A 25-second, 1920 x 1080, 30 fps product film. The creative direction combines
restrained product-launch typography with Discord-inspired interfaces and color.

- `brag.mp4`: finished H.264/AAC video, with the poster baked into frame zero.
- `brag.jpg`: standalone thumbnail.
- `share-copy.txt`: ready-to-post caption.
- `brag-plan.md`: storyboard and product claims.
- `composition-brief.md`: production brief.
- `composition/`: editable Hyperframes HTML, CSS, fonts, audio and animation.

The interfaces use fictional server content. They demonstrate building out a
server the bot has joined, configuring roles and channel settings, posting a
message, reading a forum through the agent, and creating an event. This is an
illustrative demonstration, not a recording of live Discord changes.

## Preview and render

Requires Node.js 22+, FFmpeg and FFprobe on PATH. Commands below run from
`brag-output/composition/`. Hyperframes is pinned to 0.8.43.

```sh
npm run check
npm run dev
npx --yes hyperframes@0.8.43 render --quality delivery --fps 30 --output ../brag.raw.mp4
```

From `brag-output/`, select the settled hero at 1.8 seconds and bake it into the
first frame, preserving the rest of the edit and audio:

```sh
ffmpeg -y -ss 1.8 -i brag.raw.mp4 -frames:v 1 -q:v 2 brag.jpg
ffmpeg -y -i brag.raw.mp4 -i brag.jpg -filter_complex "[0:v][1:v]overlay=0:0:enable='eq(n,0)'[v]" -map "[v]" -map 0:a? -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a copy -movflags +faststart brag.mp4
```

The music is an original deterministic 110 BPM electronic score generated by
`composition/scripts/create-score.mjs`. Its source WAV is an intermediate;
`composition/assets/score.mp3` is the final music asset. Precomputed audio energy
in `audio-data.js` controls the subtle product light. No narration is present.
